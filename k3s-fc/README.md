## K3s server for Firecracker (and other VXLAN-less kernels)

```
onctl up -n qwe -a k3s-fc/k3s-server.sh --download /tmp/k3s.yaml
```

Identical to [`k3s/k3s-server.sh`](../k3s/k3s-server.sh), except flannel's
CNI backend is set to `host-gw` instead of the default `vxlan`. `onctl`'s
`fc` provider (Firecracker microVMs) doesn't support the VXLAN kernel
module, which makes a plain `k3s/k3s-server.sh` install crash-loop
(`failed to create vxlan device: operation not supported`). Use this
template instead of `k3s/k3s-server.sh` when provisioning with `-p fc`.

```
kubectl --kubeconfig k3s.yaml get po -A
```
OR
```
export KUBECONFIG=$PWD/k3s.yaml
```

k3s server **token** is random generated by the server script, and can be
found on `/tmp/token`.
